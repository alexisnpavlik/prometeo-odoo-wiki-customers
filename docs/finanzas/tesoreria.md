# Tesorería, Cheques y Transferencias

El control del flujo de caja es vital. Prometeo incluye módulos específicos para el manejo de cobros complejos y movimientos internos de dinero.

## Gestión de Recibos y Pagos

Cuando un cliente te paga una o más facturas, puedes generar un **Recibo**. 
Un mismo recibo puede incluir múltiples formas de pago combinadas:
*   Efectivo.
*   Transferencias bancarias.
*   Cheques de terceros.

## Manejo de Cheques

El sistema cuenta con una cartera de cheques donde puedes rastrear el estado de cada uno:
1.  **Recepción:** Cuando ingresas un cheque de tercero al cobrar una factura.
2.  **Depósito:** Cuando envías el cheque de tercero a tu cuenta bancaria.
3.  **Emisión:** Cuando generas un pago a proveedor entregando cheques propios o endosando un cheque de tercero.
4.  **Rechazo:** Si un cheque viene rechazado, el sistema te permite registrar el evento y reabrir la deuda del cliente.

## Transferencias Internas

Para mover dinero entre tus propias cajas (ej. de la Caja Mostrador a la Caja Fuerte) o cuentas bancarias, utiliza la función de **Transferencias Internas**. Esto evita que el movimiento se registre como un ingreso o gasto, manteniéndolo simplemente como un traslado de fondos.
