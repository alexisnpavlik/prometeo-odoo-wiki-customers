# Introducción al Punto de Venta (POS)

El módulo de Punto de Venta (POS) de Prometeo Odoo está diseñado para facilitar la atención rápida al cliente, manteniendo al mismo tiempo controles estrictos de seguridad y supervisión.

## Características Principales

*   **Interfaz Optimizada:** Diseñada para rapidez en la caja.
*   **Controles de Seguridad:** Perfiles de "Solo Lectura" para evitar modificaciones no autorizadas en precios o descuentos.
*   **Aprobaciones Rápidas:** Sistema integrado para solicitar autorización de un supervisor en operaciones críticas (como devoluciones o descuentos mayores al permitido).
*   **Combos y Promociones:** Soporte para venta de packs o combos de manera unificada.

En las siguientes secciones, aprenderás a utilizar las funcionalidades específicas de seguridad y aprobación en el POS.
