# Finanzas y Contabilidad

El módulo de Finanzas de Prometeo Odoo centraliza el control de ingresos, egresos y el cumplimiento de las obligaciones fiscales, específicamente la **Localización Argentina (AFIP)**.

En esta sección aprenderás a gestionar:
*   Facturación Electrónica mediante webservices de AFIP.
*   Emisión de recibos y cobros.
*   Manejo de cheques de terceros y propios.
*   Transferencias entre bancos internos.

Navega por las subsecciones para ver las instrucciones detalladas de cada proceso.
